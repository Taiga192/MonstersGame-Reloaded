# Art asset list

Generated by `node scripts/assets.ts` (do not edit by hand; edit the generator). **285 images.** Put each file at `public/assets/<id>.<ext>` (png, jpg, webp, svg or avif; extension is free, name is exact). The game picks new files up on the next page load and falls back to text/emoji for anything missing.

## Art bible (paste before every prompt / bake into your style model)

- **Style:** dark gothic fantasy, painterly digital illustration, deep crimson and violet palette with warm amber highlights, moody rim lighting, rich detail, cohesive game art style, no text, no watermark, no signature
- **Icons:** single centered subject, isolated on a transparent background, slight three-quarter view, soft top-left lighting, clean silhouette readable at 64px, game inventory icon
- **Scenes/banners:** wide cinematic composition, atmospheric depth, empty calmer area on the left for a title overlay
- **Negative prompt:** text, letters, watermark, logo, frame, border, blurry, low quality, extra limbs, cropped subject, photo, 3d render

**Workflow tips:** 1) make 6-10 hero images first (logo, hero, one banner, 2 portraits, 3 icons) and lock the look; 2) train a style model (Scenario / Leonardo LoRA) or feed them as references (Flux.2 multi-reference / Midjourney --sref); 3) generate each group in one session with the same settings; 4) export icons with a transparent background at the listed size (generate larger and downscale).

**Priority:** 1 = makes the page feel alive (do first), 2 = core content, 3 = polish.
